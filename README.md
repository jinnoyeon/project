프로젝트 배경 및 필요성
본 홈페이지 리뉴얼 프로젝트는 사용자 중심의 경험(UX) 제공을 통해 학과의 긍정적인 이미지를 구축하고, 정보 접근성을 획기적으로 개선하는 데 목적이 있습니다.

신입생 친화적 이미지 구축: 홈페이지를 통해 학과의 분위기를 부드럽고 친근하게 전달하여, 특히 신입생들이 느끼는 심리적 장벽을 낮추고 학과에 쉽게 다가올 수 있도록 합니다.

학과 정체성 시각화: 세련된 디자인과 보기 편한 구성을 활용하여 학과의 특성, 비전, 그리고 강점(핵심 분위기)을 효과적으로 표현하고 차별화된 정체성을 확립합니다.

효율적인 정보 전달: 복잡한 정보를 직관적인 탐색 구조로 개편하여, 모든 사용자가 필요로 하는 정보를 빠르고 쉽게 찾을 수 있도록 편의성을 극대화합니다.
